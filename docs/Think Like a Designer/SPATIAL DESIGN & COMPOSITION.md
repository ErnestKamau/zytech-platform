# The Biggest Mistake Developers Make

Developers design objects.

Designers design space.

Developers ask

"Where should this button go?"

Designers ask

"What space should this button live in?"

Huge difference.

# Reading Width

The best designers intentionally limit reading width.

Long paragraphs increase effort.

Short paragraphs increase clarity.

This is why premium websites often have surprisingly narrow text blocks.
