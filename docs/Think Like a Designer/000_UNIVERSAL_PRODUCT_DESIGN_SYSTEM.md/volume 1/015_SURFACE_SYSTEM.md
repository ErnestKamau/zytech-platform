# Purpose

Surfaces create the physical feeling of an interface.

Every visible element lives on a surface.

A surface communicates

Hierarchy

Depth

Importance

Grouping

Interaction

Focus

Trust

Premium quality

Users should understand where content belongs simply by observing the relationship between surfaces.

---

# Surface Philosophy

Think like an architect.

Walls.

Concrete.

Steel.

Glass.

Stone.

Wood.

Fabric.

Every material communicates something.

Digital products work the same way.

Never think

"This is a card."

Think

"This is a material floating above another material."

Surfaces create spatial understanding.

# Layer System

Every surface belongs to one layer.

Layers should never compete.

Users should always know

what is behind,

what is above,

what is active,

what is inactive.

Layering should feel effortless.

# Elevation Through Surfaces

Elevation is communicated using

Contrast

Lighting

Blur

Borders

Shadow

Motion

Transparency

Not shadows alone.

Depth is the combination of multiple visual cues.

---

# Borders

Borders define separation.

Borders should be subtle.

Prefer

1px

Soft contrast

Inner highlights

Avoid heavy outlines.

Borders support hierarchy.

Not decoration.

---

# Corner Radius

Sharp

Technical

Architectural

Minimal

Soft

Friendly

Modern

Rounded

Comfortable

Organic

Pill

Interactive

Circular

Floating Actions

Choose one radius system.

Apply it consistently.

Never mix random radii.

---

# Shadows

Shadows create believable depth.

Good shadows

Soft

Layered

Subtle

Directional

Bad shadows

Dark

Sharp

Heavy

Blurry

Shadows should reinforce hierarchy.

Never become visual noise.

---

# Glass Surfaces

Glass is a premium material.

Glass combines

Transparency

Backdrop Blur

Inner Highlight

Soft Border

Ambient Lighting

Subtle Shadow

Glass should only appear on elevated elements.

Examples

Navigation

Hero Cards

Floating Panels

Dialogs

Sidebars

Media Controls

Premium Buttons

Glass should never reduce readability.

Glass should enhance focus.

Never dominate the interface.

---

# Backgrounds

Backgrounds should remain quiet.

Avoid visual competition.

Allowed

Solid

Gradient

Subtle Noise

Soft Lighting

Image

Video

Backgrounds support content.

Content never fights the background.

---

# Textures

Texture creates realism.

Use sparingly.

Examples

Very subtle grain

Architectural concrete

Paper

Soft fabric

Brushed metal

Never allow textures to overpower typography.

---

# Lighting

Light communicates depth.

Every surface should assume one light source.

Highlights should remain consistent.

Glass requires

Outer light

Inner highlight

Ambient glow

Lighting should feel natural.

---

# Transparency

Transparency creates layering.

Transparency should

Preserve readability

Reveal context

Support hierarchy

Transparency should never reduce usability.

# Responsive Surfaces

Desktop

Greater separation.

Tablet

Balanced hierarchy.

Mobile

Simplified layering.

Small Mobile

Reduce unnecessary depth.

Responsive surfaces prioritize clarity.

---

# Accessibility

Surfaces must maintain

Readable contrast

Visible focus

Keyboard navigation

Touch targets

Reduced motion

Glass should remain readable.

Never sacrifice accessibility for aesthetics.

---

# Performance

Avoid excessive blur.

Reuse shadows.

Optimize gradients.

Minimize transparency layers.

Reduce repaint cost.

Premium should also be fast.

---

# AI Rules

AI should

Reuse Surface Tokens

Never invent materials

Respect elevation hierarchy

Reuse glass recipes

Prefer consistency

Avoid decorative shadows

Preserve readability

---

# Best Practices

Create depth through multiple cues.

Use restrained shadows.

Limit glass.

Allow whitespace to define surfaces.

Let content breathe.

Think architecturally.

Think materially.

# Common Mistakes

Too many cards.

Heavy shadows.

Glass everywhere.

Multiple border styles.

Random radii.

Competing surfaces.

Busy backgrounds.

Excessive transparency.

---

# Anti-patterns

Nested cards.

Dark borders.

Blurred body text.

Heavy glass.

Overlapping panels.

Floating elements without purpose.

Gradient cards on gradient backgrounds.

Multiple light directions.

Everything elevated.

Nothing elevated.

Surfaces should communicate structure.

Never decoration.

# Implementation

Applications consume Surface Tokens.

Components consume Surface Recipes.

Patterns compose surfaces.

Layouts define placement.

Themes define appearance.

---

# Surface Checklist

Before approving a surface

□ Does it communicate hierarchy?

□ Does it improve readability?

□ Does it belong to the correct layer?

□ Is the elevation appropriate?

□ Are borders consistent?

□ Are shadows restrained?

□ Does it support dark mode?

□ Does it support glass mode?

□ Is accessibility maintained?

□ Is it reusable?

Only then is a surface approved.

---

# Final Principle

Users should never consciously notice your surfaces.

They should simply feel that every layer has purpose.

Great surfaces quietly create depth,

reinforce hierarchy,

improve readability,

support interaction,

and make digital interfaces feel tangible, premium, and timeless.
