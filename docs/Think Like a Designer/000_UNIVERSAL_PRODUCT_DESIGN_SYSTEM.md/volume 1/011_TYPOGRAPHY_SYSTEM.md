# Purpose

Typography is the primary method of communication in digital products.

Users spend significantly more time reading than interacting.

Typography should improve understanding.

Never decoration.

Typography establishes

Hierarchy

Rhythm

Structure

Readability

Trust

Brand personality

Professionalism

Every text element should have purpose.

Components never invent typography.

They consume the Typography System.

---

# Typography Philosophy

Good typography becomes invisible.

Users should understand information effortlessly.

Typography should

Guide the eye

Reduce cognitive load

Increase readability

Support accessibility

Create rhythm

Create hierarchy

Communicate confidence

Avoid decorative typography.

Content always comes first.

# Reading Behavior

People rarely read interfaces word for word.

They scan.

Design typography to support scanning.

Users typically scan

Headings

Subheadings

Buttons

Lists

Tables

Highlighted text

Metadata

Body copy

Typography should create obvious scanning paths.

Never force users to search.
