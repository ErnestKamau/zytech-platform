# Purpose

Theme Studio is the living implementation of the Universal Product Design System.

It is the single source of truth for every design decision.

Every color.

Every spacing value.

Every typography scale.

Every component.

Every animation.

Every interaction.

Every recipe.

Every state.

Every theme.

Every project references Theme Studio.

No UI should ever be designed outside of it.
