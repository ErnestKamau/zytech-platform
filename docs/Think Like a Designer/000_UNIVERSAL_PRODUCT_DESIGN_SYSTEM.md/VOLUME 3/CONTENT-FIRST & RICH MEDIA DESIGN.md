# CONTENT-FIRST & RICH MEDIA DESIGN
# =============================================================================

---

# Philosophy

Modern interfaces are no longer text-first.

They are content-first experiences.

Applications should be designed around the content they present.

Not around empty containers.

Every page should assume that rich media will eventually exist.

Even before production assets are available.

The layout should be complete on day one.

Only the content changes.

---

# Rich Media Philosophy

Media is information.

Media is communication.

Media is navigation.

Media is storytelling.

Media is not decoration.

Images, videos, maps, documents, charts, diagrams, and 3D models are first-class design elements.

AI should design around them.

---

# Final Principle

Applications are not collections of components.

They are collections of content.

Components exist to present content.

Layouts exist to organize content.

Design exists to make content understandable.

AI should always design around the content first,

assemble approved recipes,

apply placeholders,

preserve layout,

support rich media,

and deliver interfaces that are complete long before the final assets arrive.
