# Purpose

This document teaches AI how to design.

Not by inventing.

By composing.

AI should never create random interfaces.

AI should assemble interfaces from approved design recipes.

Every generated UI should feel like it belongs to the same product family.

---

# Philosophy

AI is not a designer.

AI is an architect.

Architects do not invent bricks.

They compose buildings from proven systems.

AI should do the same.

Everything begins with tokens.

---

Every interface follows the same hierarchy.

# Core Rule

AI should never ask

"What should this button look like?"

Instead ask

"Which approved button recipe solves this problem?"

# Placeholder Rules

AI should never assume final assets exist.

Every design should support placeholders.

Supported placeholders

Hero Images

Project Images

Construction Photography

Videos

Maps

Blueprints

Documents

PDF Preview

Logos

Profile Images

Product Images

Background Images

Before & After Galleries

3D Renders

Charts

Maps

Timelines

Every placeholder preserves layout.

Never allow layout shift.

---

# Skeleton Rules

Whenever content loads asynchronously

Prefer Skeletons

Instead of

Loading Spinner

Skeletons should resemble final layouts.

Never use generic placeholder bars when meaningful skeletons exist.

---

# Motion Rules

Motion communicates state.

Not decoration.

Preferred motion

Fade

Scale

Slide

Glass Spotlight

Hover Elevation

Shimmer Sweep

Progress Reveal

Page Transition

Reduced Motion

Respect operating system accessibility settings.

---

# Glass Rules

Glass is intentional.

Not decorative.

Recommended usage

Navigation

Hero Cards

Premium Buttons

Dialogs

Command Palette

Floating Panels

Search

Filters

Settings

Avoid glass on every surface.

Contrast remains the priority.

---

# Accessibility Rules

AI must validate

Contrast

Keyboard Navigation

Focus States

Touch Targets

ARIA

Reduced Motion

Readable Typography

Logical Hierarchy

Accessibility is never optional.

---

# Performance Rules

AI should optimize

Images

Videos

Animations

Blur Effects

Rendering

Virtual Lists

Lazy Loading

Skeleton Loading

Avoid unnecessary DOM complexity.

---

# Theme Rules

AI must support

Light Theme

Dark Theme

Glass Theme

High Contrast Theme

Brand Themes

Future Themes

No component should depend on a single theme.

---

# Component Selection Rules

Never invent components.

Always search Theme Studio.

If recipe exists

Reuse it.

If recipe does not exist

Recommend creating one.

Never duplicate components.
