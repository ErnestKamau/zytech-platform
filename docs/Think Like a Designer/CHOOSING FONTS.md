# Weight Is More Important Than Font

Many people obsess over changing fonts.

Professionals first adjust

Weight

Spacing

Hierarchy

Scale

Often, a single font family with multiple weights creates a stronger, more cohesive design than combining several unrelated fonts.

---

# Variable Fonts

Modern font families often include a continuous range of weights.

Benefits

Smaller downloads

Smoother animations

Greater flexibility

Consistent rendering

Whenever possible, prefer variable fonts.

---

# Performance Matters

Typography affects performance.

Every extra font

Every extra weight

Every extra file

Adds network requests and increases page weight.

Aim for

One family

Three or four weights

Variable font when available

Good design is also efficient.
