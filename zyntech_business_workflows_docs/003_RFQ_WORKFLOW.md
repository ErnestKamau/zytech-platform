# RFQ Workflow

## Meaning

An RFQ is a customer request for Zyntech to provide pricing and commercial terms.

It is not an invoice, order, or quote.

## Lifecycle

```text
Draft
 -> Submitted
 -> Under Review
 -> Quoted
 -> Closed / Cancelled
```

## RFQ Sources

- Customer portal
- Product page
- Cart
- Sales/customer-service staff
- Project workflow

## RFQ Item Types

### Catalog Product

Product, SKU, quantity, requested delivery, notes.

### Custom Requirement

Description, specifications, dimensions, material, brand, quality requirements, attachments, drawings, reference documents.

### Service

Installation, transport, consultation, site inspection, labour.

An RFQ may contain mixed products and services.

## Zyntech Review

Staff can:

- Review requirements
- Request clarification
- Add internal notes
- Attach documents
- Prepare a quote

## Clarification

Incomplete requirements should support a clarification process instead of forcing an incomplete quote.

## Audit Events

Examples:

- Created
- Submitted
- Viewed
- Clarification requested
- Customer responded
- Quoted
- Cancelled
- Closed
